== OPEN DECISIONS (settle at INIT Phase 0) ==
- [ ] App stack / shell: native Swift (SwiftUI menu-bar app) vs Python + native
      UI (mirror transcriber) vs Electron/Tauri. Must support a reliable global
      hotkey, menu-bar presence, and system-wide text insertion. Leaning native
      Swift menu-bar for lowest latency and cleanest macOS hotkey + Accessibility
      insertion; to be decided with the stack spike.
- [ ] Default transcription backend: on-device mlx-whisper / parakeet-mlx
      (reuse transcriber) for the always-available fast path, with Groq
      whisper-large-v3-turbo as an optional cloud fast path. Confirm on-device
      latency is low enough to feel instant for short dictations.
- [ ] Text insertion mechanism: Accessibility API (AXUIElement) paste vs
      simulated keystrokes vs clipboard-paste-and-restore. Needs a spike — this
      is the riskiest "insert at cursor, anywhere" piece.
- [ ] AI cleanup: which models/techniques ship as selectable options (none /
      local LLM / Groq llama / Claude), and the default. Cleanup must be fast
      enough not to add perceptible lag, or run async after insertion.
